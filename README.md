# পরীক্ষার হল — উপস্থিতি তথ্য সংগ্রহ (GitHub Pages সংস্করণ)

এই অ্যাপে একাধিক কক্ষ পরিদর্শক আলাদা আলাদা ডিভাইস থেকে তথ্য দেবেন এবং সবার তথ্য
একসাথে (রিয়েল-টাইম) সারাংশে দেখা যাবে — এই জন্য একটা ফ্রি **Firebase Realtime
Database** ব্যবহার করা হয়েছে। GitHub Pages শুধু ফাইল হোস্ট করে, ডাটা রাখতে পারে
না — তাই ডাটা রাখার জন্য Firebase লাগবে। নিচের ধাপগুলো একবার করলেই হয়ে যাবে।

## নতুন কী যোগ হয়েছে
- 🗓️ **মাল্টি-ডে পরীক্ষা সাপোর্ট** — পরীক্ষা একাধিক দিন ধরে চললে হেডারে "＋ নতুন দিন" চেপে প্রতিটি দিন যোগ করুন এবং দিনের চিপ থেকে বেছে নিন। প্রতিটি দিনের ডাটা, সারাংশ, প্রিন্ট ও এক্সপোর্ট আলাদাভাবে সংরক্ষিত ও দেখানো হয়।
- 📴 **অফলাইন ড্রাফট সেভ** — টাইপ করার সাথে সাথে তথ্য স্বয়ংক্রিয়ভাবে ডিভাইসে (localStorage) খসড়া হিসেবে সেভ হতে থাকে। ইন্টারনেট না থাকলেও কিছু হারাবে না; সংযোগ ফিরলে "সংরক্ষণ করুন" চাপলে সার্ভারে জমা হবে।
- ⚠️ **আনসেভড চেঞ্জ ওয়ার্নিং** — কোনো কক্ষের তথ্য পরিবর্তন করে "সংরক্ষণ করুন" না চেপে অন্য কক্ষ/দিনে যেতে চাইলে বা পেজ বন্ধ করতে চাইলে একটা সতর্কবার্তা দেখাবে (তবে ড্রাফট স্থানীয়ভাবে সেভ থাকেই, তাই ডাটা হারানোর ভয় নেই)।
- 📄 **সরাসরি PDF এক্সপোর্ট (A4)** — সারাংশ ট্যাবে "PDF ডাউনলোড করুন" বাটনে চাপলে কোনো প্রিন্ট ডায়ালগ ছাড়াই সরাসরি A4 মাপের একটা PDF ফাইল ডাউনলোড হয়ে যাবে।
- 📲 **হোম স্ক্রিনে ইনস্টল (PWA)** — অ্যাপটি এখন ফোনের হোম স্ক্রিনে আইকন হিসেবে ইনস্টল করা যাবে (একটা ইনস্টল ব্যানার নিজে থেকে দেখাবে), এবং একবার খোলা হলে অফলাইনেও অ্যাপের মূল পেজ লোড হবে।
- 🔒 **কক্ষ-ভিত্তিক পিন** — প্রথমবার একটা কক্ষে "সংরক্ষণ করুন" চাপলে সেই কক্ষের জন্য একটা ৪-৬ সংখ্যার পিন সেট করতে বলবে (ডিভাইসের localStorage-এ মনে রাখা হয়)। পরের বার সেই কক্ষে সেভ করতে গেলে একই পিন চাইবে — ভুল কক্ষে ডাটা ঢুকে গেলে পিন না মিললে সতর্ক করবে।
- 🕘 **এডিট হিস্ট্রি / অডিট ট্রেইল** — এন্ট্রি ট্যাবে "পরিবর্তনের ইতিহাস দেখুন" বাটনে চাপলে সেই কক্ষে এ পর্যন্ত কে, কখন, কত জনের তথ্য দিয়ে সংরক্ষণ করেছেন তার পুরো তালিকা দেখা যাবে।
- 🔍 **সারাংশ টেবিলে সার্চ/ফিল্টার** — "বিষয়ভিত্তিক উপস্থিতি" টেবিলে বিষয়/শ্রেণি দিয়ে এবং "কক্ষভিত্তিক তথ্য" টেবিলে রুম নম্বর দিয়ে সরাসরি খুঁজে ফিল্টার করা যাবে।
- 📈 **দিনভিত্তিক তুলনা চার্ট** — একাধিক দিনের পরীক্ষা থাকলে সারাংশ ট্যাবে একটা লাইন চার্টে দিন-ভিত্তিক মোট উপস্থিতির প্রবণতা/তুলনা দেখা যাবে।
- 📋 **রোল-ভিত্তিক হাজিরা শিট** — প্রতিটি শ্রেণির নিচে রোল নম্বরের তালিকা/রেঞ্জ (যেমনঃ 101-140, 145) লিখে দিলে সেই কক্ষের জন্য একটা প্রিন্ট-উপযোগী রোল-ভিত্তিক হাজিরা শিট (চেকবক্সসহ) ডাউনলোড করা যাবে — "রোল-ভিত্তিক হাজিরা শিট ডাউনলোড করুন" বাটনে চাপুন।
- 📑 **CSV এক্সপোর্ট** — Excel-এর পাশাপাশি এখন "CSV ফাইল ডাউনলোড করুন" বাটন দিয়েও কক্ষ/বিষয়/শ্রেণিভিত্তিক তথ্য একটা CSV ফাইলে পাওয়া যাবে, যা প্রায় যেকোনো সফটওয়্যার বা গুগল শিটে সরাসরি ইমপোর্ট করা যায়।

## ফাইলসমূহ
- `index.html` — মূল ওয়েবসাইট
- `firebase-config.js` — আপনার Firebase প্রজেক্টের কনফিগারেশন (নিচের ধাপ অনুযায়ী পূরণ করতে হবে)
- `manifest.json` — PWA ম্যানিফেস্ট (হোম স্ক্রিনে ইনস্টলের জন্য প্রয়োজনীয়)
- `sw.js` — সার্ভিস ওয়ার্কার (অফলাইন ক্যাশিং ও ইনস্টলযোগ্যতার জন্য প্রয়োজনীয়)
- `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` — অ্যাপ আইকন
- `README.md` — এই নির্দেশনা

> নিচের ধাপ ৪-এ GitHub Pages-এ আপলোড করার সময় **উপরের সবকটা ফাইল** (README বাদে) রিপোজিটরির root-এ দিতে হবে — শুধু `index.html` আর `firebase-config.js` দিলে হোম স্ক্রিন ইনস্টল ফিচার কাজ করবে না।

## ধাপ ১: ফ্রি Firebase প্রজেক্ট তৈরি করুন
1. https://console.firebase.google.com এ যান, Google অ্যাকাউন্ট দিয়ে লগইন করুন।
2. **Add project** / **Create a project** এ ক্লিক করুন। একটা নাম দিন (যেমনঃ `exam-attendance`)।
   Google Analytics লাগবে না, চাইলে বন্ধ রাখতে পারেন।
3. প্রজেক্ট তৈরি হয়ে গেলে বাম পাশের মেনু থেকে **Build → Realtime Database** এ যান।
4. **Create Database** চাপুন। লোকেশন যেকোনোটা রাখতে পারেন। প্রথমে
   **"Start in test mode"** বেছে নিন (এতে সাথে সাথে পড়া-লেখা কাজ করবে; পরীক্ষার
   সময়ের জন্য যথেষ্ট, তবে নিচে ধাপ ৩-এ নিরাপত্তা রুলস দেওয়া আছে সেটাও বসিয়ে নিন)।

## ধাপ ২: Web App কনফিগারেশন কপি করুন
1. Firebase কনসোলে প্রজেক্টের **Settings (⚙️ আইকন) → Project settings** এ যান।
2. নিচে **"Your apps"** সেকশনে `</>` (Web) আইকনে ক্লিক করে একটা নতুন Web App যোগ করুন
   (নাম যা খুশি দিন, Firebase Hosting-এর দরকার নেই, ওটা স্কিপ করুন)।
3. এখন আপনাকে একটা `firebaseConfig` অবজেক্ট দেখানো হবে, যেমন:
   ```js
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "exam-attendance-xxxx.firebaseapp.com",
     databaseURL: "https://exam-attendance-xxxx-default-rtdb.firebaseio.com",
     projectId: "exam-attendance-xxxx",
     storageBucket: "exam-attendance-xxxx.appspot.com",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef123456"
   };
   ```
4. এই পুরো মানগুলো কপি করে `firebase-config.js` ফাইলে গিয়ে একই নামের
   `firebaseConfig` অবজেক্টের জায়গায় বসিয়ে দিন (প্লেসহোল্ডার মানগুলো মুছে ফেলুন)।

   > `databaseURL` টা সবচেয়ে গুরুত্বপূর্ণ — এটা না থাকলে বা ভুল থাকলে ডাটা সেভ হবে না।
   > Realtime Database তৈরির সময় এটা স্বয়ংক্রিয়ভাবে কনফিগারেশনে যোগ হয়ে যাওয়ার কথা;
   > না থাকলে Realtime Database পেজের উপরে URL থেকে কপি করে নিন।

## ধাপ ৩: ডাটাবেস রুলস বসান (নিরাপত্তার জন্য প্রস্তাবিত)
Firebase কনসোলে **Realtime Database → Rules** ট্যাবে গিয়ে এটা বসান, তারপর **Publish**:
```json
{
  "rules": {
    "examData": {
      ".read": true,
      ".write": true
    },
    "examMeta": {
      ".read": true,
      ".write": true
    }
  }
}
```
এটা শুধু `examData` (প্রতিটি দিনের কক্ষ-তথ্য ও এডিট হিস্ট্রি) ও `examMeta` (দিনগুলোর তালিকা ও
রোল নম্বর তালিকা) পাথে পড়া-লেখার অনুমতি দেয় (test mode-এর মতো পুরো ডাটাবেস উন্মুক্ত রাখার
চেয়ে নিরাপদ) — নতুন ফিচারগুলো (এডিট হিস্ট্রি, রোল তালিকা) একই পাথের ভেতরে থাকে বলে এই
রুলস আলাদাভাবে পাল্টাতে হবে না। পরীক্ষা শেষ হয়ে গেলে দুটোরই `.write` কে `false` করে দিলে
আর কেউ তথ্য পরিবর্তন করতে পারবে না, কিন্তু সবাই ফলাফল দেখতে পারবে।

> আগের সংস্করণে ডাটা `rooms` পাথে থাকত। এই সংস্করণে মাল্টি-ডে সাপোর্টের জন্য পাথ পাল্টে
> `examData/<তারিখ>/rooms` করা হয়েছে। আগের কোনো ডাটা থাকলে সেটা নতুন পাথে ম্যানুয়ালি
> কপি করে নিতে হবে (Firebase কনসোলের Realtime Database ভিউ থেকে)।

## ধাপ ৪: GitHub Pages-এ আপলোড ও চালু করা
1. GitHub-এ একটা নতুন রিপোজিটরি তৈরি করুন (Public হতে হবে ফ্রি GitHub Pages-এর জন্য)।
2. `index.html`, `firebase-config.js` (আপনার নিজের মান বসানো অবস্থায়) — এই দুটো
   ফাইল রিপোজিটরির root-এ আপলোড করুন (README.md ঐচ্ছিক)।
3. রিপোজিটরির **Settings → Pages** এ যান।
4. **Source** এ `Deploy from a branch` বেছে নিন, Branch: `main`, Folder: `/ (root)`
   বেছে নিয়ে **Save** করুন।
5. কিছুক্ষণ পর (সাধারণত ১-২ মিনিট) একটা লিংক পাবেন, যেমনঃ
   `https://<আপনার-ইউজারনেম>.github.io/<রিপোজিটরির-নাম>/` — এটাই আপনার লাইভ ওয়েবসাইট।

## পরীক্ষা করে দেখুন
- লিংকটা খুলে একটা কক্ষের তথ্য দিয়ে "সংরক্ষণ করুন" চাপুন।
- অন্য একটা ডিভাইস/ব্রাউজার ট্যাব থেকে একই লিংক খুলে "সারাংশ ও প্রিন্ট" ট্যাবে
  গিয়ে দেখুন তথ্যটা রিয়েল-টাইমে দেখা যাচ্ছে কিনা।
- প্রিন্ট বাটন এবং "রিপোর্ট ফাইল ডাউনলোড করুন" বাটন — দুটোই এখন সাধারণ ব্রাউজার
  ফিচার ব্যবহার করে, তাই GitHub Pages-এ স্বাভাবিকভাবেই কাজ করবে।

## PWA (হোম স্ক্রিন ইনস্টল) সম্পর্কে
- ইনস্টল কাজ করতে GitHub Pages-এর HTTPS লিংক লাগবে (এমনিতেই পাবেন, আলাদা কিছু করতে হবে না)।
- অ্যান্ড্রয়েড/ক্রোমে সাইট খুললে একটা "ইনস্টল করুন" ব্যানার নিজে থেকে দেখাবে। iPhone/iPad-এর
  Safari-তে এই ব্যানার আসবে না (Apple-এর সীমাবদ্ধতা) — সেখানে শেয়ার (Share) বাটন থেকে
  **"Add to Home Screen"** বেছে নিতে হবে; অ্যাপে সেই নির্দেশনা দেখানো হবে।
- ভবিষ্যতে `index.html`, `manifest.json` বা `sw.js` আপডেট করে আবার আপলোড করলে `sw.js`
  ফাইলের শুরুতে `CACHE_NAME = 'exam-hall-shell-v1'` লাইনের ভার্সন নম্বর (v1 → v2 ইত্যাদি)
  বাড়িয়ে দিন — নাহলে যাদের ফোনে আগে থেকে ইনস্টল করা আছে তারা পুরনো ক্যাশ করা সংস্করণ দেখতে থাকবেন।

## সমস্যা হলে
- **তথ্য সেভ হচ্ছে না:** `firebase-config.js`-এ কনফিগারেশন ঠিকভাবে বসানো হয়েছে কিনা
  এবং Realtime Database Rules-এ `rooms` পাথে write অনুমতি আছে কিনা যাচাই করুন।
  পেজের উপরের ব্যানারে (লাল/হলুদ বক্স) আসল এরর মেসেজ দেখাবে।
- **সারাংশে তথ্য আসছে না:** Rules-এ `read` অনুমতি আছে কিনা দেখুন, এবং ব্রাউজারের
  ডেভেলপার কনসোলে (F12) কোনো এরর আসছে কিনা দেখুন।
- **PDF/Excel বাটনে কাজ হচ্ছে না:** এই দুটো ফিচার ইন্টারনেট থেকে একটা ছোট লাইব্রেরি লোড করে
  (প্রথমবার), তাই সংযোগ না থাকলে কাজ করবে না। ইন্টারনেট সংযোগ যাচাই করে আবার চেষ্টা করুন।
- **ইনস্টল ব্যানার দেখাচ্ছে না:** একবার ব্যানার বন্ধ (✕) করলে সেটা আর দেখাবে না — ব্রাউজারের
  ঠিকানা বার/মেনু থেকে সরাসরি "Install app" অপশন খুঁজে নিতে পারেন।
