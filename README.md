# পরীক্ষার হল — উপস্থিতি তথ্য সংগ্রহ (GitHub Pages সংস্করণ)

এই অ্যাপে একাধিক কক্ষ পরিদর্শক আলাদা আলাদা ডিভাইস থেকে তথ্য দেবেন এবং সবার তথ্য
একসাথে (রিয়েল-টাইম) সারাংশে দেখা যাবে — এই জন্য একটা ফ্রি **Firebase Realtime
Database** ব্যবহার করা হয়েছে। GitHub Pages শুধু ফাইল হোস্ট করে, ডাটা রাখতে পারে
না — তাই ডাটা রাখার জন্য Firebase লাগবে। নিচের ধাপগুলো একবার করলেই হয়ে যাবে।

## ফাইলসমূহ
- `index.html` — মূল ওয়েবসাইট
- `firebase-config.js` — আপনার Firebase প্রজেক্টের কনফিগারেশন (নিচের ধাপ অনুযায়ী পূরণ করতে হবে)
- `README.md` — এই নির্দেশনা

## ধাপ ১: ফ্রি Firebase প্রজেক্ট তৈরি করুন
1. https://console.firebase.google.com এ যান, Google অ্যাকাউন্ট দিয়ে লগইন করুন।
2. **Add project** / **Create a project** এ ক্লিক করুন। একটা নাম দিন (যেমনঃ `exam-attendance`)।
   Google Analytics লাগবে না, চাইলে বন্ধ রাখতে পারেন।
3. প্রজেক্ট তৈরি হয়ে গেলে বাম পাশের মেনু থেকে **Build → Realtime Database** এ যান।
4. **Create Database** চাপুন। লোকেশন যেকোনোটা রাখতে পারেন। প্রথমে
   **"Start in test mode"** বেছে নিন (এতে সাথে সাথে পড়া-লেখা কাজ করবে; পরীক্ষার
   সময়ের জন্য যথেষ্ট, তবে নিচে ধাপ ৩-এ নিরাপত্তা রুলস দেওয়া আছে সেটাও বসিয়ে নিন)।

## ধাপ ২: Web App কনফিগারেশন কপি করুন
1. Firebase কনসোলে প্রজেক্টের **Settings (⚙️ আইকন) → Project settings** এ যান।
2. নিচে **"Your apps"** সেকশনে `</>` (Web) আইকনে ক্লিক করে একটা নতুন Web App যোগ করুন
   (নাম যা খুশি দিন, Firebase Hosting-এর দরকার নেই, ওটা স্কিপ করুন)।
3. এখন আপনাকে একটা `firebaseConfig` অবজেক্ট দেখানো হবে, যেমন:
   ```js
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "exam-attendance-xxxx.firebaseapp.com",
     databaseURL: "https://exam-attendance-xxxx-default-rtdb.firebaseio.com",
     projectId: "exam-attendance-xxxx",
     storageBucket: "exam-attendance-xxxx.appspot.com",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef123456"
   };
   ```
4. এই পুরো মানগুলো কপি করে `firebase-config.js` ফাইলে গিয়ে একই নামের
   `firebaseConfig` অবজেক্টের জায়গায় বসিয়ে দিন (প্লেসহোল্ডার মানগুলো মুছে ফেলুন)।

   > `databaseURL` টা সবচেয়ে গুরুত্বপূর্ণ — এটা না থাকলে বা ভুল থাকলে ডাটা সেভ হবে না।
   > Realtime Database তৈরির সময় এটা স্বয়ংক্রিয়ভাবে কনফিগারেশনে যোগ হয়ে যাওয়ার কথা;
   > না থাকলে Realtime Database পেজের উপরে URL থেকে কপি করে নিন।

## ধাপ ৩: ডাটাবেস রুলস বসান (নিরাপত্তার জন্য প্রস্তাবিত)
Firebase কনসোলে **Realtime Database → Rules** ট্যাবে গিয়ে এটা বসান, তারপর **Publish**:
```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".write": true
    }
  }
}
```
এটা শুধু `rooms` পাথে পড়া-লেখার অনুমতি দেয় (test mode-এর মতো পুরো ডাটাবেস উন্মুক্ত রাখার
চেয়ে নিরাপদ)। পরীক্ষা শেষ হয়ে গেলে `.write` কে `false` করে দিলে আর কেউ তথ্য পরিবর্তন
করতে পারবে না, কিন্তু সবাই ফলাফল দেখতে পারবে।

## ধাপ ৪: GitHub Pages-এ আপলোড ও চালু করা
1. GitHub-এ একটা নতুন রিপোজিটরি তৈরি করুন (Public হতে হবে ফ্রি GitHub Pages-এর জন্য)।
2. `index.html`, `firebase-config.js` (আপনার নিজের মান বসানো অবস্থায়) — এই দুটো
   ফাইল রিপোজিটরির root-এ আপলোড করুন (README.md ঐচ্ছিক)।
3. রিপোজিটরির **Settings → Pages** এ যান।
4. **Source** এ `Deploy from a branch` বেছে নিন, Branch: `main`, Folder: `/ (root)`
   বেছে নিয়ে **Save** করুন।
5. কিছুক্ষণ পর (সাধারণত ১-২ মিনিট) একটা লিংক পাবেন, যেমনঃ
   `https://<আপনার-ইউজারনেম>.github.io/<রিপোজিটরির-নাম>/` — এটাই আপনার লাইভ ওয়েবসাইট।

## পরীক্ষা করে দেখুন
- লিংকটা খুলে একটা কক্ষের তথ্য দিয়ে "সংরক্ষণ করুন" চাপুন।
- অন্য একটা ডিভাইস/ব্রাউজার ট্যাব থেকে একই লিংক খুলে "সারাংশ ও প্রিন্ট" ট্যাবে
  গিয়ে দেখুন তথ্যটা রিয়েল-টাইমে দেখা যাচ্ছে কিনা।
- প্রিন্ট বাটন এবং "রিপোর্ট ফাইল ডাউনলোড করুন" বাটন — দুটোই এখন সাধারণ ব্রাউজার
  ফিচার ব্যবহার করে, তাই GitHub Pages-এ স্বাভাবিকভাবেই কাজ করবে।

## সমস্যা হলে
- **তথ্য সেভ হচ্ছে না:** `firebase-config.js`-এ কনফিগারেশন ঠিকভাবে বসানো হয়েছে কিনা
  এবং Realtime Database Rules-এ `rooms` পাথে write অনুমতি আছে কিনা যাচাই করুন।
  পেজের উপরের ব্যানারে (লাল/হলুদ বক্স) আসল এরর মেসেজ দেখাবে।
- **সারাংশে তথ্য আসছে না:** Rules-এ `read` অনুমতি আছে কিনা দেখুন, এবং ব্রাউজারের
  ডেভেলপার কনসোলে (F12) কোনো এরর আসছে কিনা দেখুন।
